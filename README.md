# Tarjeta Guía · Conquistadores

Sitio para acompañar la tarjeta de clase **Guía** del Club de Conquistadores.

- **`index.html`: Mi tarjeta Guía.** Seguimiento de todos los requisitos (I–IX y la clase avanzada Guía de Exploración), con estado, fecha, notas, opciones elegidas, lecturas bíblicas y copia de seguridad. Todo se guarda en el navegador.
- **`remedios.html`: Ocho remedios naturales.** Página para cumplir el requisito **V.1** ("Hacer una presentación, para alumnos de enseñanza básica, sobre los ocho remedios naturales dados por Dios"). Incluye una rueda interactiva, un modo presentación para proyector (flechas/deslizar, o abrir `remedios.html#presentar`), un quiz de 8 preguntas, un desafío de 7 días y un registro que marca V.1 como completo en el seguimiento.

Los proyectos que ya están en marcha aparecen vinculados a **VII.2 (Ecología)**: el monitoreo diario del AQI de Lima (30/08 al 28/09) y el trabajo de bichos.

Para usarlo, abrí `index.html` en el navegador o publicalo con GitHub Pages (Settings → Pages → rama `main`, carpeta raíz).
